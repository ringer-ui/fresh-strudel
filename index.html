Cheat sheet

      
The bar at the top sets the defaults (BPM, key, drum kit). tempo() and key() in your code override them.


      
Instruments

      
Each one starts a track. Chain any Strudel method after it.

      

        
drums("kick ~ snare ~")
kick snare hat openhat clap rim tom crash ride

        
drums({ kick: "x...x...", … })
step grid, 16 steps = 1 bar, no spaces in a row. x hit · X accent · o ghost · . rest

        
bass("0 ~ ~ 0 ~ -2 ~ 3")
numbers are notes of your key (0 = root); ~ is a rest. Note names like c2 eb2 work too

        
chords("<Cm7 Fm7>")
chord names, voiced for you

        
pad("<Cm7 Fm7>")
slow, soft, reverby chords

        
lead("~ ~ 4 ~ ~ 2 ~ 0")
melody, an octave up, with a little echo

      


      
Options

      
Second argument: bass("0 3", { vol: .5, filter: 300 })

      

        
vol
0–1 loudness

        
pan
0 left · .5 centre · 1 right

        
filter / hipass
low-pass / high-pass cutoff in Hz

        
reverb · delay
0–1 amount

        
sound
sawtooth, square, triangle, sine, or a sample name

        
octave
bass and lead only

        
attack · release
seconds

        
bank
drums only, e.g. "RolandTR808"

      

      
Any other Strudel control works too: { crush: 4 }.


      
Chain shortcuts

      

        
.vol(x) .hipass(x) .reverb(x)
same as the options

        
.bars(n)
stretch over n bars (.slow)

        
.sweep(200, 4000, 8)
filter opens and closes over 8 bars

        
.humanize()
loosen the timing

      


      
Paste any Strudel song

      
Songs from the Strudel REPL run here too: $: and $name: tracks, setcpm(), gm_* instruments and drum-machine names. Visualisers like ._pianoroll() and slider() are accepted but not drawn.


      
Everything else

      
All of Strudel works: .fast(2) .every(4, rev) .sometimes(…) .degradeBy(.3) .jux(rev) and <a b> [a b] a*2 a(3,8) mini-notation.

      
Name a track with a label: groove: drums(…). Start a line with _ to mute it.

      
Ctrl/⌘ Enter play/update · Ctrl/⌘ . stop · Ctrl/⌘ K command palette

      
Alt N / Alt P select the next / previous number (then type a new one, drag its slider, or turn a MIDI knob) · the small slider after a number edits it live
